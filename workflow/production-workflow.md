# Football Special — Production Workflow

## Overview

Football Special uses an AI-assisted workflow to create short-form football storytelling videos.

## 1. Story Research

Find an interesting football story and identify the key events that should be included.

## 2. Scriptwriting

Create a short, engaging story designed for short-form video.

The script focuses on:

- A strong hook
- Important events
- Emotional moments
- A clear story progression
- A memorable ending

## 3. Scene Planning

Break the script into individual visual scenes.

Each scene is matched to a specific part of the narration.

## 4. AI Image Generation

Create visual scenes using AI image-generation tools.

The prompts focus on:

- Character appearance
- Age
- Location
- Clothing
- Action
- Lighting
- Camera angle
- Cinematic style
- 9:16 composition

## 5. Voiceover

Generate the narration using an AI voiceover tool.

## 6. Video Editing

Combine the generated images and voiceover.

Additional elements include:

- Captions
- Background music
- Sound effects
- Zoom and pan effects
- Transitions
- Branding

## 7. Final Export

Export the finished video in a vertical 9:16 format suitable for short-form platforms.

## 8. Publishing

Publish the finished video to:

- YouTube Shorts
- TikTok
- Instagram Reels

## Future Automation

The long-term goal is to automate more of the workflow using programming and AI APIs.

Possible future automation:

Story → Script → Scene Prompts → Images → Voiceover → Video → Publishing
